# Журнал решений (ADR-lite)

Формат: `D-NNN · дата · статус (принято | нужно подтверждение | отменено)`. Контекст → решение → альтернативы.

---

### D-001 · 2026-10-30 · принято
**Экспорт через Luna (Unity Playworks), Unity 6000.0 LTS + URP 17.0.x.**
Контекст: лимит 5 MB single-HTML у AppLovin и Unity Ads. Обычный Unity Web build с трудом укладывается в 5 MB даже пустым.
Альтернативы: Unity Web build + свой упаковщик в HTML (большой риск по размеру); переписать на JS-движок (уходим из Unity).

### D-002 · 2026-10-30 · принято
**Без DOTS/ECS и без физического движка. Data-oriented C# (SoA), собственные коллизии по маскам.**
Контекст: в Luna нет DOTS/Burst/Jobs, 2D-физика исторически нестабильна. Нужно 600–1000 ракет на слабом Android.

### D-003 · 2026-10-30 · нужно подтверждение (по итогам этапа 0)
**Разрушаемость: CPU-маска + `Texture2D` по грязным тайлам.** Фоллбэк — штамповка в RenderTexture.
Решается спайком на этапе 0: работает ли быстрая запись в текстуру в Luna-сборке.

### D-004 · 2026-10-30 · нужно подтверждение
**Число пушек по умолчанию: синий 3, красный 12** (референс: 1 и 14).
Контекст: при одной пушке игрок проигрывает от первого же ответного залпа, а плеебл должен давать победу.

### D-005 · 2026-10-30 · нужно подтверждение

### D-008 · 2026-10-30 · принято
**Playworks Plugin 7.2.0 подключён локальным UPM-пакетом и лежит вне репозитория.**
Контекст: дистрибутив весит 590 MB и должен лежать вне проекта (рекомендация документации Luna).
Решение: в `Packages/manifest.json` — `"com.unity.playworks.upp": "file:../../Unity Playworks Plugin/7.2.0/scripts"`. Путь относительный, поэтому на другой машине папка `Unity Playworks Plugin` должна лежать рядом с папкой проекта.
Альтернативы: копия `scripts` в `Packages/` (отрывает пакет от `engine`/`pipeline`/`tools`); весь дистрибутив в git (590 MB).

### D-009 · 2026-10-30 · принято
**Пакеты: добавлен URP 17.0.4, удалены неиспользуемые `com.unity.feature.2d`, `timeline`, `visualscripting`, `multiplayer.center`, `collab-proxy`.**
Контекст: в проекте не было URP, хотя стек его требует. `com.unity.feature.2d` с URP давал ошибки компиляции в `2d.pixel-perfect`, а `timeline` есть в списке неподдерживаемых пакетов Luna (`supported-packages.json`).
Альтернативы: чинить версии 2D-пакетов (не нужны: арт идёт через свои меши и uGUI).

### D-010 · 2026-10-30 · принято
**Цветовое пространство — Gamma.**
Контекст: минимальная платформа — WebGL 1, где Linear опирается на необязательные sRGB-расширения. Цвета в арте и шейдерах считаем в гамме.
Альтернатива: Linear (риск расхождения цветов между устройствами, выигрыша для плоской мультяшной графики нет).

### D-011 · 2026-10-30 · нужно подтверждение (по итогам Luna-сборки)
**Динамические меши обновляются через `Mesh.vertices` / `Mesh.colors32` с переиспользуемыми массивами; поля элементов пишутся на месте.**
Контекст: в Luna 7.2.0 нет перегрузок `SetVertices(Vector3[], …)`, `SetVertexBufferData`, `LoadRawTextureData`, `SetPixelData`. Для тайлов масок есть только `SetPixels32`. `Vector3[]` и `Color32[]` выделяются один раз в `Init`, в горячем цикле меняются только поля `x/y/r/g/a`, поэтому копий struct-ов нет.
Фактическую цену этих вызовов в JS покажет HUD спайка (строка `ms`).

### D-012 · 2026-10-30 · принято
**Сборка Luna запускается через `Tools/luna_build.py`.**
Контекст: `project:build` пишет задание `Assets/.export-assets` и ждёт экспорта, а `LunaCLI.Export` в batchmode выполняет это задание. Поодиночке оба зависают, и даже вместе Jake не замечает конец экспорта. Поэтому скрипт запускает их вместе, затем завершает Jake и отдельно выполняет `assets:bundle`, `code:bundle`, `package:bundle`. Нужен вход в Playworks Plugin, Unity должна быть закрыта.

### D-013 · 2026-10-30 · принято
**Итоговый HTML под сети собирается только в Luna Playground.**
Контекст: в плагине 7.2.0 локально есть только шаблоны `develop` и `playground`, сборка с `TARGET_PLATFORM=applovin` падает. Поэтому бюджеты размера проверяются после загрузки архива в Playground, локально виден только размер архива.
