# Этап 07 — Арт-пасс в стилистике Bowmasters, UI, звук

**Статус: стоп-точка, ждём апрув style sheet.** Готов только первый шаг этапа: лист стиля. Игра внешне не изменилась: новая палитра записана в `ThemePalette.cs`, но `ThemePalette.asset` не тронут. Весь остальной арт, атласы, UI и звук начнутся после апрува. 341 EditMode-тест зелёный. Luna-сборка не собиралась: в игровом коде ничего не поменялось.

## Сделано
- Цвета сняты пипеткой со скриншотов `bowmasters_graveyard`, `bowmasters_city`, `bowmasters_desert` и записаны в пресеты `Night` и `Sunset`.
- Растеризатор `Tools/flat_svg.py`: плоские SVG с токенами палитры, один файл рисуется в обеих темах.
- Образцы в `Art/Source/Style`: два макета сцены, два кадра 720×1280, EndCard, лента объектов крупно.
- Лист `docs/reports/img/style_sheet.png`: наши макеты рядом со скриншотами Bowmasters, образцы, все HEX.

## Как проверить (шаги для заказчика)
1. Открыть `docs/reports/img/style_sheet.png`.
2. Сравнить две верхние пары: скриншот слева, наш макет справа. Вопрос один: похоже ли на одну игру.
3. Посмотреть образцы крупно: кромка земли, замки, бустеры, ракеты, взрыв, HUD, рука.
4. Посмотреть кадры 720×1280 и EndCard.
5. Ответить `APPROVED` или `FEEDBACK:` с правками, например «фон на ступень темнее».

## Что смотреть особенно (механика / графика)
- Земля `Night`: бирюзовая масса вместо тёмно-зелёной из ТЗ.
- Кремовый камень замков вместо сиреневого.
- Панель HUD светлее, чем в ТЗ, плашка POWER / ANGLE белая.
- Шрифт Rubik вместо Fredoka или Baloo 2.
- Состав сцены на макетах сжат ради сравнения со скриншотом. Настоящие масштаб и форма уровня не меняются.

## Известные проблемы и долги
- Кромка запекается в маску одна на сборку: капли `Night` и фестон `Sunset` одновременно не поместятся, для `Sunset` маску надо перепекать.
- Новые поля палитры появятся в `ThemePalette.asset` только после сброса пресетов, это первый шаг после апрува.
- Тест палитры переписан: ближний слой `Night` теперь светлее леса (D-054).
- `pngquant` в системе нет. Оптимизацию PNG решу на шаге атласов; если понадобится этот инструмент, спрошу.
- Звуки пока не начаты, требуют отдельного решения по источнику.
